# Takım Stok Kontrol

Tek sayfa stok kontrol uygulaması (Excel / Alternatif DB / NC program).

## GitHub Pages

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** → folder **/ (root)** → **Save**

Birkaç dakika sonra:

**https://erdotsc.github.io/takim-stok-kontrol/**

Veri tarayıcıda kalır (localStorage). Ortak stok için Excel veya JSON yükleyin. Şirket içi ortak klasör için localhost sunucusu kullanın.
